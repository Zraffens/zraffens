## Things I've Built

### 🎨 Skribbl-ML Bot

**Real-time handwriting / drawing recognition using deep learning**

A real-time ML system that recognizes drawings while they are being created.

The project combines a React frontend with a FastAPI backend and a PyTorch inference pipeline communicating over WebSockets.

I experimented with different representations of drawing data, including variable-length sequences of:

```text
(Δx, Δy, pen-state)
```

and compared sequential models such as **1D-CNNs and GRUs** against spatial image-based approaches.

The best-performing model reached approximately **96% accuracy with sub-5 ms inference**, making it fast enough for interactive use.

**Stack:**  
`Python` `PyTorch` `FastAPI` `React` `WebSockets` `Scikit-learn`
